# クラフト画面と挙動

クラフト画面は VirtualContainer のチェスト画面（1行9マス、最大54スロット）で作る。完成品スロットには本物を置き、量が減ったことをクラフト確定とみなす。

## レイアウト（27スロット・3×3の場合）

```text
 ■  [ ][ ][ ]  ■  ■  ■  ■  ■
 ■  [ ][ ][ ]  ■  →  [完成] ■  ■
 ■  [ ][ ][ ]  ■  ■  ■  ■  ■
```

- ■ は穴埋め用アイテム（後述）、→ は矢印。どちらもアドオンが定義する専用の UI アイテム（`craft:ui_*`）
- グリッドサイズは色ごとに 2×2 / 3×3 / 5×5 などを選べる（54スロットなら最大 6×6 程度）
- タイトルは色ごとの表示名。サイズとタイトルは作成後に変えられないので、設定を変えたときはコンテナを作り直す
- コンテナはプレイヤーごとに別々に作る（1つのコンテナを複数人で共有しない）
- 見た目の変更（JSON UI で特定タイトルの画面だけ描き替える）はオプション。更新で壊れやすいので、既定では使わない

## 穴埋め用アイテム

使わないスロットには、バニラのコンテナ画面の背景と同じテクスチャを持つアイテムを置き、スロットの穴を背景に溶け込ませて隠す。JSON UI を触らずに、作業台らしい見た目に近づけられる。

- アイテム ID は `craft:ui_filler`。リソースパックでバニラの背景と同じ色・質感のテクスチャを割り当てる
- 矢印（`craft:ui_arrow`）も、同じ背景の上に矢印を描いたテクスチャにすると、バニラの作業台画面に近くなる
- スタック上限1、クリエイティブのインベントリには出さない（通常の入手手段をなくす）
- ホバー時のツールチップを目立たせないよう、表示名は空に近い文字列にする
- 画面の外で見つかったら即削除する（[アイテム監視](05-item-monitoring.md)）
- 要検証：アイテムアイコンはスロットの内側に描かれるので、スロットの枠線がどこまで残るか。カーソルを重ねたときのハイライトがどう見えるか

## 完成品スロットのルール

カーソルには `clear()` しかなく、アイテムを置く手段がない。このため「目印付きのプレビュー品を取らせて本物とすり替える」方式は使えない。

| 起きたこと                                             | 処理                                                                                                                  |
| ------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------- |
| グリッドが変わった                                     | レシピを判定し、完成品スロットに本物を置く（一致しなければ空にする）                                                  |
| 完成品がすべて取られた                                 | 材料を1回分消費し、コストを支払わせ、報酬コマンドを実行し、再判定する                                                 |
| 完成品が一部だけ取られた（右クリックで半分など）       | 1回分のクラフトとして消費し、スロットに残った分はインベントリへ（満杯なら足元にドロップ）                             |
| 完成品スロットにアイテムが置かれた・重ねられた         | 増えた分をプレイヤーに返す                                                                                            |
| 材料の消費に失敗した（同じ tick で材料が変わったなど） | カーソル・インベントリ・地面から完成品を回収する                                                                      |
| 画面を閉じた                                           | グリッドに残ったアイテムをインベントリに返す（満杯なら足元にドロップ）。`PlayerLeft` の場合は退避して次回参加時に返す |

一括クラフトが必要なら、「×1 / ×8 / 最大」のボタン用 UI アイテムを置く方式で後から追加する。
