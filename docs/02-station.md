# ステーション（16色の作業台）

ステーションはブロックの種類（色）で識別し、ブロック自体にはデータを持たせない。壊しても、爆発しても、`/clone` やストラクチャーで複製しても設定が壊れない。

- バニラの染料と同じ16色（white, orange, magenta, light_blue, yellow, lime, pink, gray, light_gray, cyan, purple, blue, brown, green, red, black）を、`craft:workbench_<color>` という 16 個の別ブロック ID として定義する
  - 状態（state）で色を持たせるとアイテムが1種類になり、`/give` やクリエイティブのインベントリで色を選べないため、別 ID にする
  - `menu_category` の group で1つにまとめ、クリエイティブ画面では折りたたんで表示する
  - 右クリックの処理は共通のカスタムコンポーネント（1つの実装）
- 色ごとの設定（表示名＝コンテナのタイトル、グリッドサイズ、レシピ一覧）はワールド側に保存する
- 使えるプレイヤーを絞る設定は色ごとには持たない。絞りたいときはレシピごとの条件（必要なタグ）を使う（docs/07-recipe.md）
- 同じ色はどこに置いても同じレシピになる
- 未設定の色を開いた場合、管理者には「未設定の作業台です（/craft:admin で設定）」、一般プレイヤーには「何も作れない」と表示する
- 染料による色の塗り替えは、付けるなら既定で OFF（塗り替えると別のステーションのレシピが使えてしまうため）
- サバイバル用の作業台のクラフトレシピは同梱しない。必要なら「作業台クラフトレシピ追加パック」を別の小さなアドオンとして配布する
- 形違い（金床型・祭壇型など）の作業台は作らない。ステーションは16色だけ。設定のキーは保存済みのデータに合わせて `table_<色>`（例：`table_red`）のまま残す
