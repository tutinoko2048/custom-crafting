# 概要と前提

スクリプトを書けないワールド製作者が、名前・説明文・エンチャント付きのアイテムを使った独自レシピをゲーム内だけで作れるようにする。

| 項目         | 内容                                                                                                                                          |
| ------------ | --------------------------------------------------------------------------------------------------------------------------------------------- |
| 対象ユーザー | 配布マップ・RPGマップ・サーバーのワールド製作者（非開発者）                                                                                   |
| 導入方法     | ビヘイビアパックとリソースパックを入れるだけ。設定はすべてゲーム内で行う                                                                      |
| 動作要件     | ワールド設定で「ベータ API」実験トグルを ON。対応する Minecraft のバージョンを明記する（Preview 26.70.24 で VirtualContainer が beta に追加） |
| 使う主な API | VirtualContainer（beta）、カスタムコマンド、CustomForm（DDUI）、StructureManager、ワールドのダイナミックプロパティ                            |

## バニラの作業台との違い

専用の3×3作業台だけなら、ブロックの `minecraft:crafting_table` コンポーネントとレシピ JSON でスクリプトなしでも作れる。このアドオンは、バニラにできない次の点に絞る。

- 名前・説明文・エンチャントなどを含むアイテムをそのまま材料や完成品にできる
- アドオンを編集せず、ゲーム内でレシピを追加・変更できる
- 経験値・スコアのコスト、タグによる解放条件、クラフト時のコマンド実行
- 作業台（色）ごとに異なるレシピセット
