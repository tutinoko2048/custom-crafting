# アイテム監視（持ち出し・複製対策）

lockMode はエンティティのインベントリでしか効かない。そのため UI アイテムが画面の外に出たら必ず回収し、元のスロットに戻す。`virtualContainerItemChange` はプレイヤーの操作でだけ発火する after イベントで、操作をキャンセルできない。

| 移動経路                                              | 検知方法                                                                                           | 対応                                           |
| ----------------------------------------------------- | -------------------------------------------------------------------------------------------------- | ---------------------------------------------- |
| スロット ⇄ カーソル（マウス・コントローラー）         | `virtualContainerItemChange` ＋ `playerCursorItemGrab` / `Release` ＋ `minecraft:cursor_inventory` | カーソルを `clear()` し、スロットを元に戻す    |
| スロット → インベントリ（Shift クリック・タッチ操作） | `itemChange` をきっかけにインベントリを走査                                                        | インベントリから削除し、スロットを元に戻す     |
| 画面の外へドラッグしてドロップ                        | `entitySpawn` で `minecraft:item` を検知                                                           | アイテムエンティティを消し、スロットを元に戻す |
| ドラッグで複数スロットに分配                          | `itemChange` が複数回発火                                                                          | 1 tick 分をまとめて処理する                    |

- UI アイテムはすべてアドオン専用の ID（`cw:ui_*`）にするので、ID だけで判定できる
- カーソル・インベントリ・地面のチェックは、画面を開いているプレイヤーにだけ行う
- cursor inventory はタッチ操作では使われない。スマホではインベントリの走査が唯一の検知手段になる
- 画面を閉じた後も念のため一度インベントリを走査し、取りこぼしを消す
