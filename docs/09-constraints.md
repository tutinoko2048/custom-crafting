# 制約・要検証事項

最大のリスクは複製バグと、beta API の仕様変更。実装に入る前に次を確かめる。

- [ ] `place` した保管用エンティティを同じ tick で取得できるか（できなければ1 tick 待って範囲検索）
- [ ] 起動時にプレイヤーがいない専用サーバーで、tickingarea を使って読み込めるか
- [ ] 穴埋め用アイテムでスロットの枠線やホバー時のハイライトがどう見えるか
- [ ] 1 tick 内に複数の `itemChange` が起きたときの順番と、完成品の取り出しと材料変更が同じ tick に重なった場合の挙動
- [ ] タッチ操作（カーソルなし）で、UI アイテムの持ち出しをすべて検知できるか
- [ ] バンドルやシュルカーボックスをグリッドに入れたとき、中身ごと正しく扱えるか
- [ ] チート OFF のワールドで `/craft:open` をコマンドブロックから動かせるか（`cheatsRequired`）

配布時の説明書には「ベータ API を ON にすること」「Minecraft の更新で動かなくなる可能性」「対応バージョン」を必ず書く。
